Interpretation

TP2 shards transformer weights, but DreamZero's per-chunk workload has modest token count and batch size. The profiler shows TP2 spends about one third of critical-rank wall time in NCCL all-reduce, so communication and synchronization eat most of the expected compute reduction.

CFG parallel instead separates the positive and negative guidance branches. That duplicated denoising work is close to embarrassingly parallel and needs little cross-rank communication, so it cuts the chunk latency much more effectively.

Method: communication is NCCL-covered GPU time; compute is remaining GPU kernel/memcpy/memset time; CPU wait is residual profiled request wall time. GPU communication wins overlaps. Raw artifacts:
